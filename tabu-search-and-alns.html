Tabu Search & ALNS

Two ways to improve a plan when trying every possible plan would take too long. Learn the main ideas first, then test your memory.

Start with these simple words

Imagine planning a delivery route. A solution is one complete route. The objective is what you want to improve, such as total distance. Constraints are rules, such as the truck’s weight limit.

A neighbor is another plan made by an allowed change. A local optimum is a plan where none of the changes you currently check gives an improvement—even though a better plan may exist elsewhere.

Current = where I am now. Best = the best plan I have found so far.

All cost examples below use “lower is better.” These methods seek good answers; they do not generally prove that an answer is the best possible.

01 / MEMORY

Tabu Search

“Change the plan. Remember recent moves. Avoid going straight back.”

Tabu means temporarily forbidden. Think of a short “do not undo this yet” list.

The basic loop

  1. Start with a plan; save it as the best.
  2. Check nearby plans, often using small changes.
  3. Choose the best allowed candidate checked—even if it is worse than the current plan.
  4. Move there. Update the tabu memory and the best plan.
  5. Repeat until the stopping limit; return the best.

Words to remember

  • Tabu list: records recent move features to discourage returning.
  • Tenure: how long a restriction lasts.
  • Aspiration: an exception, commonly allowing a tabu move that beats the best found.
  • Intensification: search promising areas more closely.
  • Diversification: explore different areas.

Check → Choose → Move → Remember

Restrictions reduce cycling; they do not prevent every repeat forever. Longer tenure blocks more options; shorter tenure may allow quick returns.

A simple example

Tabu Search: allow a temporary setback

Your route costs 100. The best allowed candidate costs 103. You move to 103, but keep 100 as your saved best. Later you find 95: now the saved best becomes 95.

If a tabu move would give 94 while the saved best is 95, the usual best-improving aspiration rule allows it.

Test yourself

Say your answer aloud before opening each card.

1. Why allow a worse plan?

It can help the search leave a place where nearby improvements have run out. Keep the best plan safely saved.

2. Does “tabu” mean forbidden forever?

No. Restrictions expire, and an aspiration rule can override them.

3. What two plans must you distinguish?

The current plan and the best plan found so far. They may be different.

02 / REBUILDING

ALNS

“Remove some parts. Rebuild the plan. Favor methods that help.”

Adaptive Large Neighborhood Search changes a chunk of a plan and adjusts how often it uses different methods.

The basic loop

  1. Start with a plan; save it as the best.
  2. Choose a destroy method and a repair method.
  3. Remove some parts, then put them back to create a candidate.
  4. Use an acceptance rule to decide whether to move there. Keep track of the best.
  5. Reward useful methods and update their selection weights. Repeat; return the best.

Words to remember

  • Destroy: remove selected parts.
  • Repair: rebuild the missing parts.
  • Operator: a method for removal or rebuilding.
  • Adaptive: past results affect future method choices.
  • Weight: a higher value usually means a greater chance of being chosen.

Choose → Remove → Rebuild → Accept? → Learn

Simulated annealing is a common acceptance rule: sometimes allow a worse plan, usually less readily as the search cools. ALNS can use other rules.

A simple example

ALNS: rebuild part of a route

Your route visits A → B → C → D → E. Remove B and D, leaving A → C → E. Try inserting B and D in new positions. Check the cost and delivery rules before deciding whether to use the rebuilt route.

A removal method might pick random stops. A repair method might choose the cheapest valid insertion positions.

Test yourself

Say your answer aloud before opening each card.

1. What makes ALNS adaptive?

It changes the chances of choosing methods based on their results. Removing and repairing alone is not the adaptive part.

2. Does repair mean “guaranteed improvement”?

No. Repair creates a complete candidate. Its quality and validity still need checking.

3. Does a high operator weight guarantee selection?

No. With weighted random selection, it means a higher chance, not a promise.

4. What two plans must you distinguish?

The current plan and the best plan found so far. They may be different.

The difference to learn by heart

QuestionTabu SearchALNS
Main idea?Guide changes using memory.Remove and rebuild using adaptive method choices.
Typical change?A swap or a move.Rearrange several parts together.
What is remembered?Recent move features; sometimes longer-term patterns.How useful the operators have been.
Main settings?Moves to try, tabu tenure.Operators, removal size, weight updates, acceptance rule.

These are typical patterns, not strict limits on every implementation. In both methods, check constraints or handle violations explicitly.

Your 20-second answer

Tabu Search uses memory to avoid immediately reversing recent changes. ALNS removes and rebuilds parts of a plan, then learns which methods to use more often. Both explore alternatives and keep the best answer found.
